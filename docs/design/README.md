# デザイン資料

デザイン一式のハンドオフ（2026/10/07 受領）のうち、見た目の参考になるものを置いています。

- `DESIGN_SPEC.md` … デザイントークン（色・文字・角丸）と画面ごとの内容
- `screens/` … モックアップ画像

**作る範囲は CLAUDE.md（PoC 要件）が優先です**（D3）。このデザイン資料にある次の要素は作りません。

- 検品履歴の画面と下部タブ
- WMS への送信・出荷確定
- カタログ本体のバーコード照合
- 撮影画像への検出枠の描画（AI の読取結果は座標を持たない）

使うのは、デザイントークン（`apps/web/src/theme` に定義）、オーダー確認画面と判定結果画面のレイアウト・文言のトーンです。
NG の表現はアクセント色 `#F05A22` で行い、緑・赤の状態色は使いません（D5）。
